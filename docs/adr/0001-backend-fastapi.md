# ADR 0001 — Backend: FastAPI (Python 3.12)

- **Status:** Accepted
- **Date:** 2026-05-13
- **Deciders:** @orrin

## Контекст

Учебный проект `pulse` — полевые учения инфраструктуры будущего
коммерческого Pulse (AI-ассистент-экосистема для российских селлеров на
WB/Ozon/ЯМ). Стек должен максимально совпадать со стеком Pulse: каждая
строчка кода и каждое инфраструктурное решение должны быть переносимы
1-в-1.

Backend должен уметь:
- Валидировать Telegram `initData` (HMAC-SHA256 по боту-токену).
- Отдавать простой CRUD на ~5 endpoints.
- Подключаться к Postgres.
- В дальнейшем (в Pulse) — обслуживать MCP-серверы и Claude-агенты.

## Рассмотренные варианты

### FastAPI (Python 3.12) ✅ выбрано

**За:**
- Совпадает с языком Pulse-бэка → переносимость 100%.
- Pydantic снимает ручную валидацию initData и DTO.
- Зрелый официальный MCP SDK (`mcp` от Anthropic) на Python — важно для Pulse.
- Богаче готовых обёрток для WB/Ozon API в русскоязычном сегменте.
- Один язык с ботом (`aiogram`).
- Alembic — boring и надёжный, прод-проверенные миграции.

**Против:**
- Контейнер ~150MB (vs ~50MB у Node) — приемлемо.
- Async-экосистема местами шершавая (драйверы БД, GIL) — для CRUD не релевантно.
- Чуть больше boilerplate.

### Hono + TypeScript

**За:**
- Маленький, быстрый, элегантный фреймворк.
- Общие типы с фронтом — приятная DX.
- Drizzle ORM современнее Alembic.

**Против (решающее):**
- **Расходится со стеком Pulse.** Каждая практика, полученная здесь, потребует
  трансляции на Python. Это противоречит самой цели проекта.
- MCP-серверы на TS работоспособны, но Python-референсы доминируют.
- Edge-преимущества (Cloudflare Workers) не работают — хостинг на VPS.

### Litestar / Starlette / Django Ninja

Не рассматривались всерьёз: FastAPI закрывает требования, имеет
максимальное сообщество, тренирует «дефолтный» паттерн.

## Решение

**FastAPI.** Не потому что объективно лучший фреймворк (Hono элегантнее),
а потому что Hono в этом контексте — ловушка: дёшево сейчас, дорого через
3 месяца, когда учебный код придётся переписывать для Pulse. Учения теряют
смысл.

## Последствия

- В `backend/pyproject.toml` фиксируем `python ^3.12`, `fastapi`, `pydantic`,
  `sqlalchemy[asyncio]`, `alembic`, `asyncpg`, `uvicorn`.
- Пакетный менеджер — **uv** (см. README).
- Тесты — `pytest` + `pytest-asyncio`.
- Линт — `ruff` (быстро, минимум конфига).

## Открыто на будущее

- Когда Pulse подключит MCP-серверы, переносим паттерны `init_data.py` и
  `deps.current_user` из этого репо дословно.
